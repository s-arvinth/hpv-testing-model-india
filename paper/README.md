# Reproducing the paper

This folder and the `hpvcc paper` command regenerate the simulations, results tables and
figures of the paper from the fitted parameters, with fixed seeds.

```bash
hpvcc paper all              # every simulation, table and figure (~15 min on 80 cores)
hpvcc paper list             # experiments and figures, with their sources
```

Outputs go to `results/paper/` (set `HPVCC_RESULTS` to move `results/`):

```text
results/paper/simulations/<experiment>/<unit>.npz    cached ensembles, reused by tables and figures
results/paper/tables/csv/*.csv                       master results tables (all units, coverages, years)
results/paper/tables/latex/*.tex                     the manuscript's LaTeX tables
results/paper/figures/...                            figures, same file tree as the manuscript
```

## What is in this folder

| File | Content |
|---|---|
| [`experiments.yaml`](experiments.yaml) | every simulation behind the paper: units, scenarios, ensemble sizes, draw schemes, seeds |
| [`reference/`](reference) | the paper's tables (`paper_tables/`), figures (`paper_figures/`) and numbers, as generated by this version; used by the regression tests |
| [`update_reference.py`](update_reference.py) | refreshes `reference/` from `results/paper/` after an intended change of results |
| [`compare_figures.py`](compare_figures.py) | rasterises regenerated and reference figures and reports pixel differences |

## Simulations

```bash
hpvcc --workers 80 paper simulate                         # all experiments
hpvcc paper simulate india_coverage_sweep                 # one experiment
hpvcc paper simulate states_coverage_sweep --unit Kerala  # one experiment, one unit
```

| Experiment | Units | Scenarios | Simulations | Time (80 cores) |
|---|---|---|---|---|
| `states_coverage_sweep` | 36 states/UTs | HPV-DNA, coverage 0–100 % in 5 % steps (21) | 1000 | ~10 min |
| `india_coverage_sweep` | India | HPV-DNA, coverage 0–100 % in 5 % steps (21) | 1000 | ~20 s |
| `india_test_type` | India | 4 tests at 75 % coverage (Fig S3 and Table S8) | 1000 | ~10 s |
| `states_test_type` | 36 states/UTs | 4 tests at 70 % coverage (Table 1 and Table S11) | 1000 | ~3 min |
| `india_test_type_70` | India | 4 tests at 70 % coverage (India row of Table 1 and Table S11) | 1000 | ~10 s |
| `india_monte_carlo` | India | 500 accepted parameter sets, no screening | — | ~1 min |

Every experiment uses the same design: `r_H ~ U(r_I, 1)` and `θ ~ U(0, γ)` redrawn every
year, seeds `default_rng([0, coverage / 0.05, simulation])`.

Results are cached; table and figure commands run a missing or out-of-date experiment
automatically (out of date = parameters or ensemble size changed). `--n-sims N` runs smaller
ensembles for a quick look (numbers then differ from the paper).

The master CSV tables in `results/paper/tables/csv/` hold every number behind these tables
and the figures (the full list is in [`tables.py`](../src/hpvcc/paper/tables.py)). Two of

literature HPV prevalence, parameter definitions).

Output files mirror the manuscript's figure folder under `results/paper/figures/`, so they
can be copied into the manuscript unchanged. `hpvcc --no-background paper figure …` (or
`paper all`) writes the same figures without a background to
`results/paper/figures_transparent/` (the model diagrams in their white-line version).

## How exact is it?

`paper/reference/` holds the tables, figures and numbers of the paper (Linux, versions of
`environment.yml`). A fresh `hpvcc paper all` reproduces them: the ensembles and LaTeX
tables exactly, the figures pixel for pixel (maps and ranked bars within anti-aliasing).

```bash
pytest -m "not slow"                      # fast checks (~1 min)
pytest                                    # + regenerated ensembles and tables vs reference/
python paper/compare_figures.py results/paper/figures paper/reference/paper_figures
python paper/update_reference.py          # only after an intended change of results
```
